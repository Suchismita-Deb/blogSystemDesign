### What is the difference between Platform Engineering and DevOps?
The two part shares the same goals of automating workflows and improving collaboration between development and operations they differ in scope.
- DevOps is a set of practices that combines software development (Dev) and IT operations (Ops) to shorten the development lifecycle and provide continuous delivery with high software quality. It focuses on collaboration between development and operations teams, automation of processes, and monitoring of applications in production.
- It emphasizes process improvement and collaboration.
- Platform Engineering is a discipline that focuses on designing and building internal platforms that enable development teams to deliver software more efficiently. It involves creating self-service platforms, tools, and infrastructure (network, servers, db) that abstract away the complexities of underlying systems, allowing developers to focus on writing code and delivering features. Platform engineering often includes aspects of DevOps, but it goes beyond by providing a more structured and standardized environment for development teams.
- It is more infrastructure centric and focuses on building reusable platforms and services.


### What is the work of a Platform Engineer?
- Platform engineers are responsible for designing, building, and maintaining the underlying infrastructure and systems that support the development and operations of applications.   
- The primary rule focuses on ensuring that the platform is scalable, secure, reliable and performant.
- Platform engineers work on automating infrastructure, integrating different systems and supporting the development teams to streamline application deployment processes.
- They may work with cloud services, CICD pipelines, containers and orchestration tools to create seamless platform environment.

The key responsibility of a platform engineer in cloud native environment include creating, managing and maintaining scalable, high-availability platform.
It includes managing cloud services like GCP and setting up and configuring containers like Dockers, Orchestrating containerized environment using tools like Kubernetes and Automating infrastructure provisioning using tools like Terraform or CloudFormation.

The role involves monitoring logging and implementing security practices to ensure that the cloud environment is secure and performant.
